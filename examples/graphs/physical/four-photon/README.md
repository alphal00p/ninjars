These six DOT files are generated by the Rust example:

```sh
cargo run -p ninjars-graph --example prepare_four_photons -- \
  target/physical/four-photon
```

`prepare_top_four_photons` admits only the Standard Model top-antitop-photon vertex, applies four-dimensional rules and shared routing, and contracts the closed internal color trace. It keeps the fermion-loop sign once in the overall factor. There is no external color projector, spin average, identical-particle phase-space factor, R2 graph, or UV counterterm.

Each JSON file binds exact momenta at a subthreshold point, MT=173, zero width, aEWM1=132507/1000, and scale²=100². The first three samples are helicities `pppp`, `ppmm`, and `mpmp`; the fourth uses explicit generic complex polarization vectors. Incoming and outgoing vector carriers are bound in their physical-leg order by the existing CLI preparation path:

```sh
ninjars prepare examples/graphs/physical/four-photon/top-box-0.json
```

The six independently generated numerators and their verified loop-momentum maps match isolated MadLoop graph numerators on quartic 70-point complex grids. See `validation/madloop/four_photon/README.md` and the `four-photon-raw*.json` evidence. The raw matching uses MadLoop's printed binary64 couplings and polarization components, so it is not a high-precision input oracle. Integrated four-photon evaluation and Ward/summed-amplitude validation remain pending.
