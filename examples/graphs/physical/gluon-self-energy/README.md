# QCD gluon self-energy (Ward-identity fixtures for R2)

The four DOT files are generated by the Rust example

```sh
cargo run -p ninjars-graph --example prepare_gluon_self_energy -- \
  examples/graphs/physical/gluon-self-energy
```

from FeynKit's Standard Model through `ninjars_graph::prepare_gluon_self_energy`,
which admits only the ghost-ghost-gluon, three- and four-gluon vertices and
the down- and top-quark gluon vertices. FeynKit supplies the Feynman-gauge
rules, the gluon-loop symmetry factor `1/2` (`gluon-loop`), the ghost-loop and
quark-loop signs `-1` (`ghost-loop`, `down-loop`, `top-loop`) and the routing;
the massless four-gluon tadpole vanishes in dimensional regularization and is
not generated. The external color tensor is projected with `delta_ab/8`, so
each numerator is the coefficient of `delta_ab`; the incoming `epsilon` and
outgoing `epsilonbar` carriers are bound by the fixtures.

Each JSON fixture has the same samples at a timelike (`p^2 = 11`) and a
spacelike (`p^2 = -22`) momentum, `MD = 0`, `MT = 173`, `aS = 59/500`:

1. `ward-*`: the incoming polarization equals `p`, the outgoing one is a
   generic complex vector;
2. `ward-both-*`: both polarizations equal `p`;
3. `generic-*`: two generic complex vectors (a nonzero control).

`p_mu Pi^{mu nu}` vanishes for the sum of the four graphs, separately for the
gauge (gluon + ghost) part and for each quark loop, in FDH:

```sh
for graph in ghost-loop gluon-loop down-loop top-loop; do
  ninjars reduce examples/graphs/physical/gluon-self-energy/$graph.json --r2 fdh
done
```

Without `--r2 fdh` the four-dimensional numerators miss the `mu^2` terms (R2)
and the Ward samples do not cancel. `crates/ninjars-cli/tests/r2.rs` checks
both.
