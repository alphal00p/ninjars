# Partial native reduction catalog

All arithmetic is generated by oneloopmaster's reusable `RustEmitter` from the
existing exact Symbolica evaluator graph. Generated files are byte-for-byte
exports, including a shared exact constant table initialized at working
precision. The runtime uses instruction-major batches and its scalar
batch-size-one path. No parallel polynomial representation or algebra is added.

| Semantic family | Input / output complex columns | Scalar native | Dual native |
|---|---:|---|---|
| T2 denominator expansion | 29 / 7 | f64, DoubleFloat, Float | Existing ordered five-component shape |
| T3 denominator expansion | 23 / 4 | f64, DoubleFloat, Float | Existing ordered five-component shape |
| Bubble source-axis projection | 28 / 8 | f64, DoubleFloat, Float | Interpreter fallback |
| Triangle-to-bubble, ordinary quotient degree 0 | 28 / 1 | f64, DoubleFloat, Float | Interpreter fallback |
| Triangle-to-bubble, ordinary quotient degree 1 | 28 / 3 | f64, DoubleFloat, Float | Interpreter fallback |
| Triangle-to-bubble, ordinary quotient degree 2 | 28 / 7 | f64, DoubleFloat, Float | Interpreter fallback |
| Triangle-to-bubble, higher quotient degree 3 | 33 / 13 | f64, DoubleFloat, Float | Interpreter fallback |
| Tadpole source projection, triangle parent | 24 / 6 | f64, DoubleFloat, Float | Existing ordered five-component shape |
| Tadpole source projection, bubble parent | 28 / 9 | f64, DoubleFloat, Float | Existing ordered five-component shape |

`with_native_denominators()` and CLI `native-denominators` retain the original
narrow selection. `with_native_kernels()` and CLI `native` select all currently
available families. Reports identify source-projection/correction families separately, alongside
other interpreted reduction, integration and accumulation. Numerator callbacks,
cut geometry and master providers are independently selected objects.
`TadpoleSourceProjection` is one reporting family with two variants selected
by the parent cut's identity. Its geometry reference probe remains interpreted
and outside this reduction selector. Unsupported Dual shapes retain the
interpreter for all newly available source projections.

The projection's ordered row is `[a0,a1,e3,e4_effective,V_triangle,E3,E4]`,
using shared FeynKit four-momenta, and outputs projections of
`[a0+V_triangle,a1,e3,e4_effective]` on E3 then E4. The source triangle origin
is preserved even when it differs from the target bubble's origin.
`TriangleBubbleSubtraction::for_quotient` selects existing exact expressions
by T2 `(t,x,mu²)` powers from `LaurentDivision`. Named native variants follow
that semantic rank/degree plan; buffer lengths only validate the selected ABI.
An empty quotient stays interpreted and produces no coefficients. The caller
retains the existing singular-denominator checks before execution.

Regenerate the new files with:

```sh
cargo run --locked -p ninjars-symbolica --features rust-codegen \
  --example generate_native_bubbles
cargo run --locked -p ninjars-symbolica --features rust-codegen \
  --example generate_native_tadpoles
```

The committed metadata lists each plan's exact dimensions and instruction
count. Regression tests regenerate and compare every emitted body and constant
byte, compare all coefficients against the interpreter in three precisions,
cover empty/single/tail/permuted batches and invalid buffer transactionality,
and check warmed f64 storage allocations. The extracted projection is also
checked against shared FourMomentum arithmetic with arbitrary complex source
origins and every higher/mixed Dual component. Dual correction subsets are
checked against the original full exact correction, including malformed shape
rejection. Integrated tests cover one- through seven-propagator stages (the
catalog is keyed by quotient degree, not by n), higher rank, accumulated
failure isolation and reset. CLI tests use archived original-Ninja total
Laurent controls.

No speedup or latency/throughput acceptance is claimed. The profiling evidence
motivated these families, but included intrusive instrumentation and interpreted
numerator callbacks. A matched, uninstrumented comparison must select and record
this catalog explicitly before performance conclusions can be drawn.
