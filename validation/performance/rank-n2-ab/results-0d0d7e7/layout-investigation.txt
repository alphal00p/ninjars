Conclusion: the width-1 replayed reduction of the smallest cases (about 450 ns, 5000
instructions per call) moves by up to 10 % with the cache-line offsets of the heap buffers in the
case-bench worker thread, which depend on the allocation history of each binary. The rank n+2
code placement does not matter. No placement change is adopted; the rank <= n+1 code is
unchanged. Layout sweep of all 27 cases (layout-sweep-ab.txt, 4 layouts x 3 runs, CPU 246):
width-1 reduction ratios B/A have geometric mean 0.996 and max 1.044 over layouts; the median
layout spread (max/min of a side's medians over the 4 layouts) is 2.0 % (max 4.7 % for A, 9.9 %
for B).
